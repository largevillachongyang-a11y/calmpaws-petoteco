# P0-2 验收说明 — 焦虑分改读服务器 `anxiety_score`

> 对应阶段：删除 APP 端焦虑分 getter，实时展示改用 `/api/status` 返回字段

## 改了什么

- `ServerApiService._parsePacket` 解析 `anxiety_score` 写入 `BlePacket.anxietyScore` 字段
- **删除** `BlePacket.anxietyScore` getter（本地公式 `strC×10 + paceD×3 + shivD×6 + strD×1`）
- **删除** `PetHealthProvider.currentAnxietyScore` getter（4 包加权均值）
- 新增 `PetHealthProvider.serverAnxietyScore`，每收到一包从服务器字段更新
- UI（`BehaviorStateCard`、`FeedingTimerCard`、Edge Impulse 调试页）改读 `serverAnxietyScore`
- **`_recentDeltas` 滑动窗口保留**（仅维护差分包，不再参与焦虑分计算）
- Mock 模式：按服务器同款公式对本 5 秒增量估算 `anxietyScore`（便于离线调试）

## 如何测试（GitHub Pages 预览）

1. 打开 https://largevillachongyang-a11y.github.io/calmpaws-petoteco/ 并 **Ctrl+F5** 强刷
2. 登录后进入 **健康（Dashboard）**
3. 确认设备栏 **Connected**（项圈在线、服务器有数据时）
4. 看 **行为状态卡** 右侧焦虑分数字/圆环

## 如何测试（浏览器 DevTools → Network）

1. F12 → **Network**，勾选 **Preserve log**
2. 过滤 `status` 或 `collar_001`
3. 点开 `GET /api/status/collar_001?key=calmpaws_secret` 的 **Response**
4. 确认 JSON 含 **`anxiety_score`** 字段（项圈静止时多为 `0`）
5. **对比 UI**：行为卡显示的焦虑分应与响应中 `anxiety_score` **一致**（四舍五入为整数），而非 APP 本地重算

示例对照：

```bash
curl -s "https://api.myvideotest2026.top/api/status/collar_001?key=calmpaws_secret"
```

记下 `anxiety_score`，与 Dashboard 行为卡数字核对。
