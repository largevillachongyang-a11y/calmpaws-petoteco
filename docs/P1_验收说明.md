# P1 验收说明 — 移除 ZenBelly 喂食流程

> 产品已确定砍掉 ZenBelly 喂食 / Time-to-Calm 流程

## 改了什么

### Dashboard
- **删除** `FeedingTimerCard`（已喂食按钮 + 计时器）
- **删除** `TimeToCalmCard`（平静用时趋势）
- 布局：设备栏 → 行为状态卡 → **焦虑历史图** → 状态小卡 → 日志

### Provider
- 移除喂食会话全套逻辑（`startFeedingSession`、计时器、Firestore 写入）
- **停写** Firestore `feeding_sessions`、`daily_stress`
- **停读** 上述两类 Firestore 数据（登录后只加载 `journal_entries`）
- 每日总结通知去掉喂食/Time-to-Calm 字段
- 健康日历改读 `/api/history` 30d/7d 日汇总

### 其他
- 我的页「健康报告」改为引导至 Dashboard 焦虑历史图
- 删除 widget 文件：`feeding_timer_card.dart`、`time_to_calm_card.dart`

## 如何测试

### 1. Dashboard 结构
1. 登录 → **健康页**
2. 确认 **无**「已喂食 / ZenBelly」大按钮
3. 确认 **无** Time-to-Calm 趋势卡
4. 行为状态卡下方应直接是 **焦虑历史** 三档图表

### 2. 无新 Firestore 写入
1. 正常使用 APP 数分钟（行为卡、图表刷新）
2. Firebase Console（若有权限）→ 用户文档下 **不应新增** `feeding_sessions` / `daily_stress` 文档
3. Network：**不应**因用户操作触发喂食相关逻辑

### 3. 健康报告入口
1. **我的** → **健康报告**
2. 应显示引导文案，指向健康页焦虑历史图

### 4. 功能无回归
- 实时 `/api/status`、行为状态卡、焦虑历史图、日志、预警通知、每日 20:00 总结仍正常
