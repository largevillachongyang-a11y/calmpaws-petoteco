## 验收步骤

### 1. 打开预览并连接

1. 打开预览 URL，登录（任意 Firebase 账号均可）。
2. Dashboard 顶部若显示「设备未连接」，点 **连接**。
3. 打开浏览器 DevTools → **Network**，筛选 `status` / `history`。

### 2. 正常有数据（200）

- Network 应看到 `GET /api/status/collar_001?key=calmpaws_secret` 返回 **200**。
- 行为卡显示宠物状态文案 + **焦虑分圆环**（数值 = 响应里 `anxiety_score`）。
- 设备栏显示 `CalmPaws 项圈 · api.myvideotest2026.top` + 电量 + SYNC。
- 焦虑历史图可切换 **24h / 7d / 30d**，底部有监测时长 footer。

### 3. 暂无缓存（204）

- 当服务器返回 **204**（项圈尚未上报或 timestamp 未变）：
  - 设备栏主文案：**等待项圈上报数据…**（琥珀色）
  - 下方说明条：已连接服务器，暂无项圈缓存数据…
  - **APP 不白屏、不报错**
- 项圈上报后下一次 **200** 应自动恢复行为卡与电量显示。

### 4. 行为 label 对齐

- 对比 Network 里 200 响应的 `label` 与行为卡 emoji/文案（如 `calm`→平静、`pacing`→踱步）。
- 焦虑历史图图例 7 色与 `dominant_state` 一致（见 `StateColors`）。

### 5. P1 回归（ZenBelly 已移除）

- Dashboard **无** 喂食计时器、**无** Time-to-Calm 卡片。
- 刷新历史图时 Network 应同时出现 3 条 `history?range=24h|7d|30d`。
