# 最终对接 P0 验收说明（Bearer + 设备绑定）

> **预览**：https://largevillachongyang-a11y.github.io/calmpaws-petoteco/  
> **测试绑定**：device_id `collar_001` · device_key `calmpaws_secret`（包装盒密钥，仅绑定时输入）

---

## 本阶段做了什么（P0）

- 全 API 改用 `Authorization: Bearer <Firebase ID Token>`（不再带 `?key=`）
- 登录后 `DeviceGate`：无绑定设备 → 绑定页；有设备 → Dashboard
- 「我的」→ **我的设备**：列表、解绑、添加
- Dashboard 多设备时下拉切换项圈
- 401 自动刷新 token，仍失败则登出

**未做（P1）**：FCM `register_fcm`、推送接收

---

## 验收步骤

### 1. 登录与绑定

1. 打开预览并登录 Firebase 账号。
2. 若从未绑定，应进入 **绑定项圈** 页。
3. 输入 `collar_001` + `calmpaws_secret` → 绑定成功 → 进入 Dashboard。

### 2. Network 鉴权

DevTools → Network，确认：

- `GET /api/user/devices` — Header 含 `Authorization: Bearer ...`
- `GET /api/status/collar_001` — **无** `?key=`，有 Bearer
- `GET /api/history/...` — 同上

### 3. Dashboard 回归

- 行为卡、焦虑历史三档、204 等待 UI、alerts 轮询仍正常。
- 设备栏显示 `项圈 · collar_001`（或英文 Collar · collar_001）。

### 4. 我的设备

「我的」→ **我的设备** → 看到已绑定项圈 → 可解绑 / 添加。

### 5. 错误码（可选，需服务器配合）

| 场景 | 期望 |
|------|------|
| 错误 device_key | 绑定页提示密钥错误 |
| 解绑后仍轮询 | 403 / 请先绑定提示 |
