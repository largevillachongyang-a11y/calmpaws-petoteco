# P0-1 验收说明 — EnvironmentConfig + API key

> 对应 PR：配置剥离（铁律 2），所有 HTTP API 请求附带 `?key=`

## 改了什么

- 新增 `lib/config/environment_config.dart`（`baseUrl` / `deviceKey` / `testDeviceId` / `requestTimeout`）
- `ServerApiService` 全部 GET/POST 经 `EnvironmentConfig.apiUri()`，自动带 `key`
- `WifiConfigService` / `ProvisioningService` 默认值改读 `EnvironmentConfig`
- 配网验证 health 路径修正为 `/api/health`（原先误为 `/health`）

## 如何测试（GitHub Pages 预览）

1. 打开 https://largevillachongyang-a11y.github.io/calmpaws-petoteco/ 并 **Ctrl+F5** 强刷  
2. 登录后进入 **健康（Dashboard）**  
3. 看顶部设备栏是否 **Connected / 实时**（项圈在线时）  
4. 进入 **宠物页**，切换 **狗/猫** 物种（会调 `POST /api/set_species?key=...`）  

## 如何测试（浏览器 DevTools → Network）

1. F12 → **Network**，勾选 **Preserve log**  
2. 刷新页面，过滤 `myvideotest` 或 `api/`  
3. 确认以下请求 URL **均含 `key=calmpaws_secret`**：

| 请求 | 方法 | 预期 |
|------|------|------|
| `/api/status/collar_001?key=...` | GET | 200 或 204 |
| `/api/app_online?key=...` | POST | 200 |
| `/api/health?key=...` | GET | 200（在服务器设置里点测试时） |

4. **不应再出现** 不带 `key` 的 `/api/status/...` 请求  

## 如何测试（服务器设置弹窗）

1. **我的 → 服务器设置**（若菜单有入口）  
2. 地址保持 `https://api.myvideotest2026.top`  
3. 点 **测试** 或 **保存** → Network 里应看到 `/api/health?key=calmpaws_secret`  

## 预期行为（功能无回归）

- 实时数据、电量、行为状态与改前一致  
- 本 PR **不改** 焦虑分来源、历史图表、喂食卡片（属 P0-2～P1）  

## 本地 curl 对照

```bash
curl -s "https://api.myvideotest2026.top/api/health?key=calmpaws_secret"
curl -s "https://api.myvideotest2026.top/api/status/collar_001?key=calmpaws_secret"
```
